Claude Certified Developer, Foundations

Simulacro orientado a desarrolladores: Messages API, tool use, MCP, prompt engineering aplicado, optimización de rendimiento/costos y Claude Code / Agent SDK.

Antes de comenzar

  • 50 preguntas de dos tipos: alternativa única (una respuesta correcta) y selección múltiple (se indica cuántas opciones elegir; solo puntúa si aciertas todas).
  • Tiempo límite: 90 minutos. Al terminar el tiempo el examen se envía automáticamente.
  • Aprobación: 72 % (36 de 50), equivalente a la escala 720/1000 del examen oficial.
  • Cada intento sortea 50 preguntas de un banco de 100, manteniendo el peso de cada dominio. El orden de preguntas y respuestas también es aleatorio.
  • Al enviar, el resultado se remite a jponce@nxtara.com.
