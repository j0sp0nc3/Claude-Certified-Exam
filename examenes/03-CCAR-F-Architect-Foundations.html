CCAR-F · Simulacro de práctica

Claude Certified Architect, Foundations

Simulacro basado en escenarios para arquitectos de soluciones: diseño de sistemas agénticos, herramientas y MCP, Claude Code en equipos, salida estructurada y confiabilidad en producción.

Antes de comenzar

  • 50 preguntas de dos tipos: alternativa única (una respuesta correcta) y selección múltiple (se indica cuántas opciones elegir; solo puntúa si aciertas todas).
  • Tiempo límite: 90 minutos. Al terminar el tiempo el examen se envía automáticamente.
  • Aprobación: 72 % (36 de 50), equivalente a la escala 720/1000 del examen oficial.
  • Cada intento sortea 50 preguntas de un banco de 100, manteniendo el peso de cada dominio. El orden de preguntas y respuestas también es aleatorio.
  • Al enviar, el resultado se remite a jponce@nxtara.com.

Dominios evaluados: Arquitectura agéntica y orquestación · Diseño de herramientas e integración MCP · Configuración y flujos de Claude Code · Prompt engineering y salida estructurada · Gestión de contexto y confiabilidad

Material de práctica elaborado para entrenamiento interno. No es contenido oficial de Anthropic ni reproduce preguntas del examen real.
